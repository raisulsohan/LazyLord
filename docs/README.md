# LazyLord documentation

LazyLord moves vectors, live text and images between **Figma, Photoshop,
Illustrator and After Effects** — any of them to any other, as real editable
layers. It is free, open source and runs entirely on your own machine.

The [README](../README.md) is the tour. These pages are the detail.

*Written for LazyLord 1.1.10.*
