LazyLord
Move vectors, live text and images between Figma, Photoshop, Illustrator and
After Effects. Everything stays on your machine.

Two steps, both in this folder. Run them in order.


STEP 1 — THE ADOBE PANEL
------------------------
  Close Photoshop, Illustrator and After Effects first.

  Windows: run "1 - Install LazyLord.bat"
  macOS:   double-click "1 - Install LazyLord (macOS).command"
           (if macOS refuses, right-click it and choose Open)

  Then start an Adobe app and open the panel:
    Photoshop      Window > Extensions (legacy) > LazyLord
    Illustrator    Window > Extensions > LazyLord
    After Effects  Window > Extensions > LazyLord

  The dot in the panel turns green when it is ready. There is no separate
  program to start and nothing to leave running in a console window: the first
  LazyLord panel you open quietly does that job for the others, and for Figma.
  Keep one panel open while you work.

  That is all you need if you only move things between the Adobe apps.


STEP 2 — THE FIGMA PLUGIN (only if you use Figma)
-------------------------------------------------
  Windows: run "2 - Add the Figma plugin.bat"
  macOS:   double-click "2 - Add the Figma plugin (macOS).command"

  It copies the plugin somewhere permanent and copies one path for you. Then,
  in the Figma DESKTOP app (the browser version cannot reach your computer):

    Menu > Plugins > Development > Import plugin from manifest...

  A file window opens — paste the copied path (Ctrl+V on Windows;
  Cmd+Shift+G then Cmd+V on macOS) and press Enter.

  Run it any time from  Plugins > Development > LazyLord.

  Figma will ask whether the plugin may talk to ws://localhost:7878. That is
  the LazyLord panel on your own machine. Nothing is sent anywhere else.

  Once the two steps are done you can delete this download folder.


USING IT
--------
  Select something, then press "Send to ..." and pick where it should go. The
  other side rebuilds it natively — real paths, real text, real layers.

  Options worth knowing:
    Existing     Add makes new layers. Update finds what LazyLord sent before
                 and replaces it where it stands.
    On conflict  What to do when you have edited that layer by hand since:
                 keep yours, or overwrite it.
    Live         Keeps one app updating as you work.


IF SOMETHING IS WRONG
---------------------
  The panel is not in the Window menu
      Restart the app. Adobe only looks for new panels while starting up.

  The panel opens blank
      Run "Fix a blank panel.bat" (macOS: in Terminal, type
      defaults write com.adobe.CSXS.11 PlayerDebugMode 1 ) and restart the app.
      Adobe's signature check fails on some machines; this tells it to load the
      panel anyway.

  The dot never turns green
      Something else may be using port 7878. Close other panels, or restart
      the app with only LazyLord open.

  Figma says it cannot connect
      Open a LazyLord panel in Photoshop, Illustrator or After Effects first,
      and use the Figma desktop app rather than the browser.

  Anything else
      The panel's Log says what happened. Copy it into an issue at
      https://github.com/raisulsohan/LazyLord/issues


REMOVING IT
-----------
  Windows: run "Uninstall LazyLord.bat".
  macOS:   delete
           ~/Library/Application Support/Adobe/CEP/extensions/com.lazylord.panel
  In Figma: Plugins > Development > Manage plugins in development > remove.
